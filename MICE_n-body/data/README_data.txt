MICE_n-body / data
==================

This directory stores input data for the MICE RAR reproduction pipeline.

1. KiDS reference data
-----------------------
Files included in this directory:
  Fig-9_RAR-KiDS-isolated_Massbin-{1,2,3,4}.txt  (KiDS isolated-galaxy RAR, Brouwer+2021)
    columns (outer->inner in file, reversed to inner->outer by scripts):
      col 0: g_bar  [m/s^2]
      col 1: g_obs  [m/s^2]
      col 2: g_obs_lo  (1-sigma lower bound)
      col 3: g_obs_hi  (1-sigma upper bound)
      col 4: r_Mpc  [Mpc]

Column ordering in Massbin-N.txt (0-indexed, inner->outer, i.e. small r first):
  col 0: g_bar  [m s^-2]
  col 1: g_obs  [m s^-2]
  col 2: g_obs_lo  (1-sigma lower bound)
  col 3: g_obs_hi  (1-sigma upper bound)
  col 4: r_Mpc  [Mpc]
  (some files have more columns; ignore columns beyond 4)

NOTE: The files are ordered outer->inner (large r first) in the original download.
      Scripts load and reverse with d[::-1, :] to get inner->outer ordering.
      Row index 4 (after reversal) = r ~ 0.164 Mpc = start of "outer 10 pts".
      Row index 14 (after reversal) = r ~ 2.604 Mpc = outermost bin.

3. CosmoHub column reference
------------------------------
Table:  mice2_mhalo  (joined with mice2_lensing where available)

Column name      Description                      Units
-----------      -----------                      -----
unique_gal_id    Unique galaxy identifier         ---
ra_gal           Right ascension                  deg
dec_gal          Declination                      deg
z_cgal           Comoving redshift                ---
lmstellar        log10(M_star / h^-2 M_sun)       dex
lmhalo           log10(M_halo / h^-1 M_sun)       dex
r_gal            Half-light radius                h^-1 Mpc
convergence      Lensing convergence kappa        ---
gamma1           Shear component 1                ---
gamma2           Shear component 2                ---

MICE2 cosmology:
  Omega_m = 0.25, Omega_Lambda = 0.75, Omega_b = 0.044
  h = 0.70, sigma_8 = 0.80, n_s = 1.00

4. Stellar mass bins (B21 Table 1)
------------------------------------
Bin 1:  9.50 <= log10(M*/Msun) < 10.30   (lmstellar: adjust for h^2)
Bin 2: 10.30 <= log10(M*/Msun) < 10.60
Bin 3: 10.60 <= log10(M*/Msun) < 10.80
Bin 4: 10.80 <= log10(M*/Msun) < 11.20

Mean M* used in HMG code:
  Bin 1: 1.5e10 Msun,  Bin 2: 3.2e10 Msun,
  Bin 3: 4.6e10 Msun,  Bin 4: 8.9e10 Msun

NOTE: MICE2 lmstellar is in h^-2 M_sun units; with h=0.70:
  log10(M*/M_sun) = lmstellar + 2*log10(0.70) = lmstellar - 0.3010
  Apply this offset when comparing to B21 bin edges (which use M_sun units).

6. Raw CosmoHub downloads (provenance)
----------------------------------------
The raw MICE2 FITS used above are obtained from CosmoHub with the queries
below; re-run them on https://cosmohub.pic.es to reproduce the same data.

File 26645.fits  —  main MICE2 galaxy catalogue (Step 01)
  CosmoHub job ID : 26645
  Table           : micecatv2_0_view  (MICECAT v2.0, Crocce+2015)
  SQL query       :
    SELECT unique_gal_id, ra_gal, dec_gal, z_cgal,
           lmstellar, lmhalo, kappa, gamma1, gamma2
    FROM micecatv2_0_view
    WHERE z_cgal BETWEEN 0.01 AND 0.50
      AND lmstellar >= 9.20
      AND dec_gal BETWEEN -5.0 AND 5.0
      AND ra_gal BETWEEN 0.0 AND 60.0
    ORDER BY unique_gal_id
  Rows    : ~2.3 million galaxies
  Columns : unique_gal_id, ra_gal, dec_gal, z_cgal, lmstellar, lmhalo,
            kappa, gamma1, gamma2
  Sky area: dec in [-5, +5] deg, ra in [0, 60] deg (1/6 of full lightcone)
  Placed at: data/MICE2_isolated/mice2_raw_test.fits

File 26646.fits  —  morphology + colour catalogue (Step 07)
  CosmoHub job ID : 26646
  Table           : micecatv2_0_view  (same sky footprint and redshift range)
  SQL query       :
    SELECT unique_gal_id, ra_gal, dec_gal, z_cgal,
           bulge_fraction, gr_cos
    FROM micecatv2_0_view
    WHERE z_cgal BETWEEN 0.01 AND 0.50
      AND lmstellar >= 9.20
      AND dec_gal BETWEEN -5.0 AND 5.0
      AND ra_gal BETWEEN 0.0 AND 60.0
    ORDER BY unique_gal_id
  Columns : unique_gal_id, ra_gal, dec_gal, z_cgal,
            bulge_fraction  (= B/T ratio directly, proxy for Sersic index),
            gr_cos          (rest-frame g-r colour from MICE SED fitting)
  Placed at: data/MICE2_isolated/07_morph_raw.fits
  NOTE    : disk_mass and bulge_mass do NOT exist in micecatv2_0_view;
            use bulge_fraction (B/T) and gr_cos instead.
